# Evaluación Parcial N°2: Análisis de Antecedentes y Evaluación Preliminar

## Descripción del Proyecto
Este proyecto consiste en un análisis exploratorio de datos (EDA) para el **Banco Financiero Global**. El objetivo principal es preparar y visualizar un conjunto de datos relacionado con campañas de marketing de depósitos a plazo para identificar patrones que permitan predecir la contratación de productos financieros.

Este trabajo forma parte de la asignatura **ADY1100 - Preprocesamiento de Datos** en Duoc UC.

## Contenido del Repositorio
* `analisis_banco.ipynb`: Notebook de Jupyter con el código de preprocesamiento y las 15+ visualizaciones solicitadas.
* `bank-additional-full.csv`: Conjunto de datos con 41,188 registros y 20 atributos de clientes.
* `.gitignore`: Archivo para excluir archivos temporales del repositorio.

## Tecnologías Utilizadas
* **Python 3.x**
* **Pandas**: Manipulación y limpieza de datos.
* **Matplotlib** & **Seaborn**: Generación de gráficos estadísticos.
* **Jupyter Notebook / VS Code**: Entorno de desarrollo.

## Instrucciones de Uso
1. Clonar el repositorio: `git clone <url-del-repo>`
